# 🌍 TravelMind AI

A modern, responsive frontend for a smart travel planning web app. Built using HTML, CSS, and JavaScript.

## ✨ Features

- Interactive travel planner UI
- Responsive design for all devices
- Smooth scrolling navigation
- Modern dark theme with gradient accents
- Feature-rich sections (Planner, Features, Future Scope)
- Clean and minimal user experience

## 🚀 Tech Stack

- HTML
- CSS
- JavaScript 

## 📌 Note

This is a **frontend-only project**.  
Backend integration (AI, APIs, automation workflows) is connected using n8n workflow.

## 📈 Future Improvements

- AI-powered trip generation
- Real-time weather and map integration
- Hotel and flight booking system
- User authentication
- Save & export itineraries
